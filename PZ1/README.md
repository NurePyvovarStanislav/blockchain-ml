# ПЗ 1 — Власний блокчейн з нуля

Навчальна локальна мережа Python: Ed25519, account-based ledger, mempool,
Merkle tree, SHA-256 Proof of Work, збереження JSON, вибір гілки за сумарною
роботою, три незалежні HTTP-вузли, CLI, атаки та експеримент.

## Підготовка (Windows PowerShell)

Відкрийте термінал у папці PZ1. Якщо `.venv` уже є й активоване,
потрібна лише команда встановлення залежностей.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux/macOS: `python3 -m venv .venv`, `source .venv/bin/activate`,
`python -m pip install -r requirements.txt`.

## Запуск трьох вузлів однією командою

```powershell
python demo_step6.py
```

Сценарій запускає три процеси (8101–8103), демонструє поширення даних,
штучне розгалуження, синхронізацію, повернення транзакції та підтвердження
на гілці-переможниці. `--pause` зупиняє сценарій між фазами;
`--base-port 8301` дозволяє обрати інші порти. Процеси зупиняються
після сценарію. Альтернативна демонстрація через CLI:

```powershell
python demo_step7.py
```

Ручний запуск та всі CLI-команди — у [README_STEP7.md](README_STEP7.md).

## Крок 8: атаки, додаткові завдання та експерименти

```powershell
python demo_step8.py --pause
python benchmark_step8.py
python simulate_majority_step8.py
python -m pytest -q
```

- demo_step8.py: п'ять відхилених атак, Merkle proof у клієнті заголовків і
  контрольована реорганізація з конфліктним переказом на більш важкій гілці.
- benchmark_step8.py: 10 реальних запусків майнера на кожному рівні 1–4;
  `--runs 30` для більшої вибірки. Зберігає час і кількість спроб;
  графік з логарифмічною віссю часу та діапазоном мінімум–максимум.
- simulate_majority_step8.py: Monte Carlo з рівною складністю блоків,
  початковим відставанням приватної гілки на три блоки й горизонтом 200
  нових блоків. Зіставляє частоту успіху з теоретичною ймовірністю
  випередження за необмеженого часу.
- CSV, графіки PNG та виведення контрольного запуску — у report_assets/.
  Для нових вимірювань в окремій папці можна задати `--out measurements`.

## Модулі

- wallet.py, transaction.py, serialization.py — ключі, підпис, TXID.
- state.py, mempool.py — баланс, резервування, nonce, прийняття транзакцій.
- block.py, merkle.py, coinbase.py — формат блока і корінь Меркла.
- difficulty.py, mining.py — Proof of Work і коригування складності.
- chain.py, storage.py — перевірка від генезису, підтвердження, JSON.
- fork.py, network.py — робота гілок, реорганізація, HTTP та розсилка.
- client.py, cli.py — клієнт без передавання приватного ключа.
- light_client.py — заголовки та Merkle proof (не повна валідація).

Історичні README_STEP2.md–README_STEP7.md містять подробиці попередніх етапів.

## Межі реалізації

Система призначена тільки для навчальної мережі на 127.0.0.1, не для реальних
коштів. Немає автентифікації локальних клієнтів, Sybil-захисту, гарантій
доставки, автоматичного збереження історії HTTP-вузла; консенсус не захищає
від коректної більш важкої гілки за більшості обчислювальної потужності.
Усі реальні приватні ключі й паролі залишаються поза репозиторієм.
