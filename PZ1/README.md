# ПЗ № 1 — Шаг 1: Ed25519-кошелёк и подписанная транзакция

Минимальный рабочий модуль первой практической работы.

## Быстрый старт (Windows PowerShell)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo.py
.\.venv\Scripts\python.exe -m pytest -q
```

Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python demo.py
.venv/bin/python -m pytest -q
```

## Что уже реализовано

- Генерация Ed25519-ключей; адрес = SHA-256 от raw 32-байтового публичного ключа.
- Сохранение приватного ключа в защищённом паролем PKCS#8 PEM (не публикуйте его!).
- Детерминированная сериализация подписываемого содержимого транзакции.
- Подпись транзакции и проверка подписи, соответствия адреса публичному ключу, формата полей и принадлежности к сети.
- TXID как SHA-256 от сериализованной подписанной транзакции.
- Автоматические тесты.

## Чего пока нет

Балансов, мемпула, проверки очередности nonce, проверки достаточности средств, блоков, майнинга, сетевых узлов. Это следующие шаги. `verify_signature()` НЕ означает, что транзакция может быть исполнена.

## Замечания безопасности

`Wallet.save_encrypted()` не перезаписывает существующий кошелёк; приватный ключ хранится в зашифрованном PEM. Используйте длинный уникальный пароль. Не загружайте файлы ключей, пароли и файлы из `wallets/` на GitHub. Программа учебная, не для реальных активов.
